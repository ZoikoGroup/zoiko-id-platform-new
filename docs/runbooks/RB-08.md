# RB-08: Poison message

**Services:** provisioning, integration · **Tier:** T2 · **Owner:** @zoiko/sre

## Trigger

A consumer repeatedly fails one event; partition stalled.

## Impact

Events behind it in the partition wait; other partitions are unaffected.

## Preconditions

Operator Console at AAL-Z3.

## Diagnosis

1. Identify the event id and type (never the payload in tickets).

## Mitigation

1. Quarantine to the dead-letter topic without blocking unrelated partitions.

## Recovery

1. Fix the consumer; replay the dead-lettered event idempotently.

## Validation

1. Partition lag back to zero; the replayed event applied once.

## Rollback

Re-quarantine if the replay fails again.

## Escalation

SEV3; SEV2 if it blocks provisioning for a tenant beyond a business day.

## Evidence

Dead-letter record with event id and reason code.
