# RB-06: Database connection exhaustion

**Services:** all cell services · **Tier:** T1 · **Owner:** @zoiko/sre

## Trigger

Pool wait time above 100 ms; `too many connections`; ready check timing out.

## Impact

Requests queue then fail; T0 paths fail closed.

## Preconditions

Admin connection reserve must stay available; never consume it for application traffic.

## Diagnosis

1. Find the source: leaked sessions, a slow query, a new release with a larger pool.

## Mitigation

1. Kill the leak or offending queries; scale pools only within approved DB limits.

## Recovery

1. Restore pool settings; confirm wait time returns to baseline.

## Validation

1. Pool wait under 10 ms p95; no 5xx from pool timeouts for 30 minutes.

## Rollback

Revert pool size changes.

## Escalation

SEV2; SEV1 if T0 journeys are failing.
