# RB-17: Cross-tenant access or authority bypass (SEV0 security incident)

**Services:** all · **Tier:** T0 · **Owner:** @zoiko/security

## Trigger

`cross-tenant-access` invariant; customer report; red-team finding.

## Impact

Possible disclosure of one tenant's data to another.

## Preconditions

Any responder may declare (`POST /ops/incidents`, severity SEV0).

## Diagnosis

1. Scope: tenants, data classes, time window, code path.

## Mitigation

1. Contain: disable the affected path or suspend affected sessions; containment overrides normal change.

## Recovery

1. Fix, test against the tenant-isolation suite, release through the emergency path (signed, admitted, reviewed).

## Validation

1. Isolation tests pass; no further violations for 24 h.

## Rollback

Keep containment until the fix is validated.

## Escalation

SEV0: incident commander, Security Lead, Legal, Privacy within 15 minutes.

## Evidence

Preserve logs, receipts and audit records; custody record for every export.
