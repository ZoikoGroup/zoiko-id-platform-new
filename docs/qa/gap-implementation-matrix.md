# ZID-GAP-001 implementation matrix (code and test inventory)

## What this is

A read-only inventory of what code and what tests exist in this repository for each of the 24 work packages (WP-01..WP-24) and for the 15-row critical security and threat-abuse catalog in ZID-GAP-001. It was built by reading files and searching test names. It is a map, not an assurance statement.

Rules used:

- Only file paths and test function names that were seen in the repository are cited. Test names are given as `path::test_name`; paths are relative to `backend/app/tests/` unless they start with `libs/` (relative to `backend/`), `tests/` or `frontend/` (relative to the repo root).
- "Covered" means a named test exists whose docstring or body exercises the behavior. It does NOT mean the test passes. No test was run, no server or Docker was started, and no existing file was edited while writing this.
- "Partial" says what is missing. "Gap" means no test or code was found.
- Many component tests (`*_pg.py`) need PostgreSQL (and some SpiceDB or Kafka); whether they are green in CI was not checked.
- Backend source paths below are relative to `backend/app/src/zid_platform/modules/`.
