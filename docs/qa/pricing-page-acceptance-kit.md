Prepared 2026-11-13 from ZID-UX-PRICE-004 v4.0, section 08. It is a procedure and a status record. It passes nothing: the document requires real test execution by people who did not build the page, with evidence, before any function is published (gate G4 for accessibility, G3 for system parity).

## Rules for executing

- Execute against a non-production environment with an ACTIVE market matrix, at least one market taken live through its rollout, one market paused, and one with an expired right.
- Record PASS, FAIL or BLOCKED. A row that waits for a signed value (a price book, a seller entity, a tier registry) is BLOCKED with that reason, never passed on a fixture.
- Rows that say 'Same as CAT-nn' are executed once, in `docs/qa/commercial-v3-cat-execution-kit.md`, and referenced here.
- Accessibility rows (P26, P27) need real devices and a screen reader. The automated structural checks are not a substitute.

## Release gates for this page

G0 scope (Product, CTO), G1 price book (CFO, CCO, Founder), G2 legal and rights (Legal, Privacy, provider owners), G3 system parity (Engineering, Finance), G4 accessibility (Design, Independent QA), G5 security (Security, SRE), G6 publish (Release authority, Commercial). Engineering cannot grant any of them.
