# Spec change requests

Raised by engineering when an ADR or the implementation finds a gap or inconsistency in a canonical spec (ADR-0000). Each CR names the target spec section, the proposed change and the evidence. The spec owner accepts, amends or rejects it; an accepted CR updates the spec and this register.
