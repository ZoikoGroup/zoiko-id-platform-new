# Migrations: `integration` module

Alembic stream owned by the **integration** module (zoiko-id-platform, ADR-0031). Version table: `zid_migrations.alembic_version__integration`.

May create or alter **only** these tables (enforced by CI against `backend/database/table-ownership.yaml`):

- `platform.integration_application`
- `platform.mapping_release`
